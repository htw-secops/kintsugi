# Application logos

Rendered from Simple Icons 13.21.0 (https://simpleicons.org), whose icon files are released under
CC0 1.0. Each PNG is the icon in white on its brand colour, 64x64 at 2x.

The names and logos are trademarks of their owners. They are used only to identify the installed
application next to its name. No logo is loaded from the network (see
`lib/presentation/applications/widgets/app_icon.dart`).

To add one: render it the same way, save it here as `<slug>.png`, and add one line to `_logos` in
`app_icon.dart`.
